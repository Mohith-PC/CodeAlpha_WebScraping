# 📚 CodeAlpha_WebScraping

## 📌 Project Overview
This project is **Task 1** of the **CodeAlpha Data Analytics Internship**.
It scrapes book data from [books.toscrape.com](https://books.toscrape.com)
using Python and saves it as a structured CSV dataset.

## 🛠 Tools & Libraries Used
- **Python**
- **BeautifulSoup4** — HTML parsing
- **Requests** — HTTP requests
- **Pandas** — Data handling & CSV export
- **Google Colab** — Development environment

## 📊 Dataset Info
- **Total Records:** 1000 books (50 pages scraped)
- **Source:** https://books.toscrape.com

| Column | Description |
|---|---|
| Title | Name of the book |
| Price | Price in British Pounds (£) |
| Rating | Star rating (One to Five) |
| Availability | In stock / Out of stock |

## 📈 Key Insights
- Average book price: **£35.07**
- Price range: **£10.00 — £59.99**
- All 1000 books scraped across **50 pages**

## 📁 Files
- `CodeAlpha_WebScraping.ipynb` — Main Colab Notebook
- `books_data.csv` — Scraped dataset (1000 books)

## 🚀 How to Run
1. Open `CodeAlpha_WebScraping.ipynb` in Google Colab
2. Run all cells in order
3. CSV will be saved and downloaded automatically
